# kokinda

Data-driven collateral pipeline for The Ritz-Carlton, Grand Cayman: merges structured
data into existing InDesign templates to produce print-ready PDF and editable INDD
output for four collateral types:

- In-room directory / guest info
- Restaurant / room-service menu
- Rate / room-type sheet
- Event / promo flyer

See [`docs/PIPELINE.md`](docs/PIPELINE.md) for how the merge workflow works and what's
needed to run it end-to-end.
