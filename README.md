# kokinda

A monorepo of small, independent Node.js services. Each app under `apps/`
has its own `package.json`, tests, and README — install and run them
separately.

## Apps

- [`apps/imessage-bot`](apps/imessage-bot/README.md) — replies to incoming
  iMessages with context-aware, per-chat responses generated by Claude, via
  a BlueBubbles server.
- [`apps/indesign-pipeline`](apps/indesign-pipeline/README.md) — wraps
  Adobe's InDesign API (Firefly Services) for template-based document
  generation, PDF-to-INDD conversion, and bulk data merge/render.

## Working in an app

```bash
cd apps/<app-name>
npm install
npm test
npm start
```
